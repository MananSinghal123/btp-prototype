# MEVRES project

prototype/ The simulator (see prototype/README.md for the file structure).
report/ LaTeX sources and figures for the dissertation.

Run the prototype (needs Python 3):
cd prototype
python -m http.server 8000 (Windows)
python3 -m http.server 8000 (macOS / Linux)
Open http://localhost:8000 in a browser. Press Ctrl+C to stop.

No Python? Double-click prototype/standalone.html instead.
