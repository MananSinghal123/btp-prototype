    Properties checked on this run

      Market simulation: unprotected DEX vs MEVRES

      The same stream of random trades and the same external price path hit two identical pools. On the unprotected pool, searchers sandwich any trade worth more than gas and arbitrage the pool back to the external price each block. On the MEVRES pool, each opportunity is auctioned and the payment is refunded.

      Cumulative user cost vs fair value (USDC)

      Cumulative LP profit: fees, less arbitrage loss, plus refunds (USDC)

      Where the extractable value went

      Sandwich value plus rebalancing arbitrage (LVR) over the whole run. Winning bidders keep the gap between their own valuation and the second-highest bid.

      Model notes. Pool is a constant-product market maker with fees held outside the reserves. Threshold encryption is modelled as AES-256-GCM with the key split by Shamir secret sharing over GF(2⁸), dealt by the user; a deployed system would use a distributed key generation so no dealer exists. Bidders report a price; the contract converts each report to a bundle value and ranks by value, so the highest value wins in both trade directions. Numbers are simulation outputs under these assumptions, not testnet measurements.
